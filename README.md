# teste-agy
Teste de código gerado com o Antigravity

O  código faz chamadas na API da Sanepar, à partir de coordenadas cadastradas previamente, e imprime na tela a manutenção vigente. O retorno é baseada na resposta da chamada na API.

Como se trata de código gerado por IA, os locais de teste não refletem endreços específicos. São locais aproximados e utilizam as centrais de abastecimento como referência. Inclusive, este foi o comportamento observado no próprio sistema da Sanepar.

O intuito é apenas automatizar e facilitar o processo das consultas. Embora o fluxo esteja centralizado, equiavale ao processo manual. Se trata de uma página estática, sem qualquer processo em segundo plano.

Todos os detalhes observados garantem um uso legal e seguro.
